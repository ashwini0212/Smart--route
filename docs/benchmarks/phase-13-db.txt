SmartRoute — Phase 13 database measurements
Run on 2026-10-06. 4-core Intel Xeon @ 2.80GHz, 15 GB RAM, PostgreSQL 17.11 in Docker on the same host.
Reproduce with: python3 scripts/perf/db_queries.py [--scale N] [--try-sql FILE]
Each number is the median of 5 EXPLAIN (ANALYZE, BUFFERS) runs after one warm-up, so the cache is warm.

3. AFTER — the real demo database (802 orders, 360k events), nothing else running
The backend was stopped for this one. With the simulators on, the same queries measured up to 20x
slower (analytics_status_counts 0.7ms -> 17ms); that is contention from a few hundred writes a
second, not the cost of the query, and it is worth knowing which of the two you are looking at.
